# 格线直测定位重构方案

## 前因（问题与根因链）

**现象（真机）**：悬浮色块向心偏移，中心≈0、边缘最大（左上角约 1/6 格）；历史上车/马/象/后偶发混淆、MedianSim 时逼 0.52 门禁。

**取证结论（本会话已完成，五环证据闭合）**：
1. 真机遥测 `BoardRect(19,1046-1251,2278)`，size=1232 ≈ 0.98×1260，顶死在 `ChessLocator.maxSize = min(sW, 0.98*sW)` 上界；
2. 真机截图格线剖面实测：真棋盘满宽 size=1260（x0=0）——真值在搜索空间之外；
3. 悬浮色块位置与"440/450 缩放矩形"逐像素吻合（450 空间 4 帧误差 ≤1px），证明 overlay 画得没错、错的是矩形；
4. 定位矩形同时喂给分类器裁剪：边缘格窗口错位最大 5.9px（48 空间），头部解剖特征取到"脖子"→ 头部余弦翻转 → 车马象后混淆；模板与运行时裁剪坐标系不同源 → MedianSim 整体压低；
5. 次级故障模式：假峰可让 size 掉到 0.87W（bug_12，size=1093），全盘乱判被门禁拦截；另有 5px 中心偏移残差（强制水平居中假设）。
6. 上下框锚点实测（用户指出，已验证）：棋盘上下各有一条全宽长矩形（上框含吃子图标带、下框为深色吃子条），二者高度不对称（下框更高更干净）。真机截图行剖面实测：上框下边界 y=1028（行 std 骤降至 0.8）、下框上边界 y=2289（std 3.6），间距 1261 = 屏宽 1260，**零误差自洽**；而纯内部格线外推的 y0≈1032 有 4px 漂移——纵向定界以上下框为主锚更稳。

**被否决的备选**：Homography/DPI 换算/霍夫四角——截图场景无透视畸变、截图与悬浮窗同坐标系（已实锤）、满宽棋盘无外框可检，属过度设计。保留手动四点校准为远期逃生门，本期不做。

## 方案核心

定位器职责切分为两级：**粗搜索只负责给近似框**（放开尺寸上界），**精标定用实测几何定终值**，且横纵分治、锚点不同源：

- **横向（x/size）——统一等差拟合，无硬分支**：不预设满宽/留边距，一律对内部纵线做等差拟合 `x_i = x0 + i·step`；满宽场景下拟合自然收敛到 x0≈0、step≈W/8，与满宽先验偏差 ≤2px 时吸附归零，否则按拟合值定案（兼容微边距机型，避免硬切满宽拉伸引入边缘误差）；
- **纵向（y）——上下框主锚 + 双重门禁**：把上下框各自解析为全宽长矩形（行均值剖面 + 行内低方差判据），**上长矩形的下边界 = 棋盘上边界，下长矩形的上边界 = 棋盘下边界**，上下框分开独立检测（不对称、锚点质量不同）。**双重门禁**：仅当 ① `下框上沿 − 上框下沿` ≈ size（误差 ≤4px）且 ② 两处 std 骤降均显著时才采信主锚；任一不满足（残局无吃子、气泡压住、夜间主题改变 std 特征等退化场景）即平滑退化为内部水平格线剖面拟合（内部 7 条分割线不受外部 UI 变化影响）；
- **假峰抑制——梳状波长先验**：峰检前用谐振梳状滤波锁定格宽波长 λ≈W/8 做周期初筛，拟合时剔除偏离等差网格过大的孤立峰，防止密集棋子轮廓（后冠、兵头）把棋子边缘冒充为分割线导致线索引错配；
- **置信度契约**：精标定统一返回 `RefineResult(rect, confidence, residual)`，残差 >2.5px 或线数不足时保持粗框并标记置信度降低，供遥测与后续门禁标定；
- 内部格线同时保留为二级证据与回退路径，并供后续"逐格非均匀边界"升级使用。误差单格内消化，"满宽/留边距"先验彻底作废，两类布局通吃。

## 阶段一：Python 原型验证（不动 App 代码）

- 新建 `tools/grid_calibrate.py`：
  - 输入粗框（沿用现有 fast_sat/comb 输出，尺寸上界临时放到 1.0W），输出精标定 rect + 诊断（检出线数、拟合残差）；
  - 纵向主锚算法：粗框上方带（粗框顶 −0.2W ~ 粗框顶）与下方带（粗框底 ~ 粗框底 +0.2W）内做全宽行均值剖面，|diff| 梯度峰检 + **行内 std 低（均匀横带）**判据筛出框边界；上区取"亮→暗/暗→亮且带内 std 骤降"的最内侧强边为上框下边界，下区对称取下框上边界；双重门禁（高≈宽 ≤4px 且两处 std 骤降显著）通过则定案，否则退化内部横线拟合；
  - 横向算法：统一等差拟合——8 行带列均值剖面 → 梳状波长 λ≈W/8 周期初筛 → 梯度峰检 → 跨行带聚类得纵线集（≥6 条）→ 剔除偏离等差网格的孤立峰 → 拟合 `x_i = x0 + i·step`；与满宽先验偏差 ≤2px 吸附归零；残差 >2px 回退粗框；
  - 内部横线剖面拟合作为纵向二级证据与退化路径，与框锚互检（实测偏差 4px 量级，门禁通过时框锚优先）；
  - 剖面用行/列带聚合，天然抗棋子遮挡断线与 JPEG 噪声；另用"合成退化帧"（涂抹/填充上下框区域）强制验证退化路径。
- 新建 `tools/validate_grid_calibration.py` 回归脚本：
  - 基准集：`pianyi_1~4`（真值 450 满宽）、`Screenshot_20260817_162715`（真值 1260 满宽）、`duolingo_1~3`、`duolingo_test_1~3`、`bug_11~20`（带边距/复杂局面，验证不回归）；已知覆盖缺口：教学关卡/无吃子栏/夜间主题帧需真机补采，补采前用合成退化帧顶替；
  - 每张图输出：粗框 vs 精标定 rect、与剖面真值的 size/x0/y0 误差、断言 |size 误差| ≤4px；
  - 重点核对：旧带边距样本不出假峰、bug_12 类假峰帧是否被精标定纠回。
- 本阶段产出数据供决策门槛：全部基准通过才进阶段二。

## 阶段二：Kotlin 移植（仅改定位层）

改 `android_copilot/app/src/main/java/com/chess/copilot/core/ChessLocator.kt`：
- `maxSize` 上界由 `0.98*sW` 放宽至 `sW`（满宽棋盘进入搜索空间；size=sW 时 x 搜索自然退化为 x=0，无副作用）；
- 新增 `refineByGridLines(gray, box): RefineResult(rect, confidence, residual)`：阶段一算法的 Kotlin 直译（行剖面复用已有灰度数组，成本毫秒级）；在 `locateTopCandidates` 返回前对 top-N 候选**逐个独立** refine（不跨候选共享锚点，严防在气泡伪候选区域内强行吸附伪边缘）；residual >2.5px 或框锚缺失且线数<6 → 保持该候选粗框并标记置信度降低（遥测落盘，供后续硬门禁阈值标定，bug_18 同款套路），不改变现有救援链路语义；
- 不动分类器、overlay、救援逻辑、门禁阈值。

## 预期收益与风险

| 项 | 现状 | 预期 |
|---|---|---|
| 悬浮层边缘偏移 | ~24px（1/6.5 格） | ≤4px（~1/40 格） |
| 裁剪窗口错位（48 空间） | 最大 5.9px | ≤1.5px |
| bug_12 类急性混淆 | 假峰 0.87W 全盘乱判 | 精标定纠回或残差门禁报警 |
| 5px 中心残差 | 存在 | 相位实测消除 |

风险：极端遮挡帧线数不足 → 已有回退粗框兜底；吃子栏退化（教学关/无吃子/主题变更）→ 双重门禁+内部格线平滑退化，合成退化帧预验；假候选伪边缘 → 逐候选独立 refine + residual 门禁；夜间/教学帧样本缺口 → 真机补采集。回滚：单文件改动，revert 即复原。

## 明确不做

- 不引入 Homography/DPI 换算/霍夫四角（场景无此需求，已论证）；
- 不改分类器特征与门禁阈值（先修根因，观察收益后再议）；
- 不做手动四点校准（保留为远期选项）。
